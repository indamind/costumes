# Демонстрационные иллюстрации и шрифты

assets/wardrobe-noir.png — шесть костюмов на тёмном готическом фоне, созданных встроенным ImageGen для этого проекта. На сайте отдельные панели выводятся средствами CSS.

Шрифты Playfair Display, Manrope и IBM Plex Mono получены из Google Fonts. Файлы шрифтов и лицензии OFL находятся в assets/fonts.

Референс оформления: https://indamind.github.io/costumes/. Сохранён небольшой SVG-знак рогов из предоставленного пользователем сайта.
