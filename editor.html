ПОСЛЕ РЕДАКТИРОВАНИЯ

Как обновить опубликованный каталог

  1. Сохрани изменения в черновик и нажми «Скачать catalog.js».
  2. Загрузи скачанный файл в корень своего репозитория, заменив прежний catalog.js.
  3. После обновления GitHub Pages новые костюмы увидят все посетители.
  4. В своём лорбуке создай запись: ключ — фраза из поля «Ключ для лорбука», содержимое — описание костюма.

Загруженные картинки входят в catalog.js. Для большого каталога лучше хранить изображения отдельно в assets и указывать путь в поле image. Архив сайта содержит инструкцию.
