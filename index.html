ИНСТРУКЦИЯ / 3 ШАГА

Один ключ
Целый образ

  1. Выбери костюм

    Открой разворот: там иллюстрация, подробное описание и точный ключ

  2. Скопируй ключ

    Название на карточке может быть длиннее ключа. Нужную фразу скопирует кнопка

  3. Впиши его в свою сцену

    Если в подключённом лорбуке есть запись с этим ключом, описание попадёт в контекст по правилам платформы Indamind AI

Важно: гардероб оживает только вместе с лорбуком. Подключи к своему персонажу лорбук, указанный на карточке костюма — сейчас это «Тёмный Гардероб», — и он узнает каждый наряд по ключу. Без лорбука ключ останется просто словом
