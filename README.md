# Гардероб — «Редакция»

Первый вариант сайта: чёрный фон, фуксия, журнальная обложка и каталог костюмов. Других дизайнов и переключателя здесь нет. Сайт работает без установки программ и сборки. Шесть костюмов и иллюстрации — демонстрационные примеры.

## Как загрузить на твой GitHub

1. Распакуй архив на компьютере. Загружать сам ZIP в репозиторий не нужно.
2. Открой свой репозиторий `costumes` на GitHub. Перед заменой сохрани копию прежних файлов, если хочешь оставить старую версию.
3. Через **Add file → Upload files** загрузи всё содержимое распакованной папки в корень репозитория: `index.html`, остальные файлы и папку `assets` целиком. `index.html` должен лежать прямо в корне, без дополнительной папки вокруг сайта.
4. Нажми **Commit changes**. Если GitHub Pages уже публикует этот репозиторий, дождись окончания новой публикации и открой `https://indamind.github.io/costumes/`.

Если используешь другой репозиторий или папку публикации, загрузи файлы в источник, выбранный у тебя в **Settings → Pages**. Все пути относительные: сайт работает и внутри `/costumes/`.

## Как добавлять свои костюмы

1. Открой ссылку **«Мастерская автора»** внизу сайта или страницу `editor.html`.
2. Нажми **«+ Новый»**, выбери изображение PNG/JPG/WebP до 2 МБ, введи название, ключ для лорбука, категорию и словесное описание.
3. Сохрани костюм в черновик. Он появится в каталоге в этом браузере.
4. Нажми **«Скачать catalog.js»** и замени этим файлом `catalog.js` в репозитории. После публикации изменения увидят все посетители.

Для изменения существующего костюма выбери его в списке редактора. Демонстрационные образы можно заменить своими.

**Черновик хранится только в твоём браузере.** Редактор не подключён к GitHub и ничего не публикует сам. Другие посетители могут изменять только свои локальные черновики. Скачивай `catalog.js` после изменений, чтобы сохранить копию коллекции. Чтобы увидеть опубликованный каталог вместо своего черновика, используй кнопку сброса черновика в редакторе.

Загруженные картинки включаются в `catalog.js`. Для большой коллекции можно хранить отдельные изображения в `assets` и вручную указывать у костюма `image: "assets/my-outfit.webp"` вместо `atlas`. Внешние адреса изображений не поддерживаются.

## Как работает название и лорбук

Под картинкой показаны название, описание и ключ. Кнопка копирует точный ключ, который пользователь вставляет в сцену. По клику на изображение открывается полное описание.

В своём лорбуке заранее создай запись с таким же ключом и описанием костюма. Например, ключ — `бархатный обет`, содержимое — словесное описание образа. Сайт помогает выбрать костюм и скопировать текст; срабатывание записи определяется настройками твоего лорбука.

В файле `catalog.js` поле `name` задаёт название, `key` — фразу для лорбука. Если отдельный ключ не указан, используется название.

## Файлы

- `index.html` — страница каталога.
- `catalog.js` — костюмы, их ключи и описания.
- `app.js`, `shared.js`, `styles.css`, `fonts.css` — оформление и работа сайта.
- `editor.html`, `editor.js`, `editor.css` — редактор локального черновика.
- `assets` — иллюстрации, локальные шрифты и их лицензии.
- `.nojekyll` — служебный файл для GitHub Pages; если он скрыт на компьютере, основные файлы сайта всё равно можно загрузить.

В каталоге работают поиск, фильтры по категориям, случайный образ, копирование ключа и описания, прямые ссылки на костюмы. Есть мобильная версия. Для предварительного просмотра открой `index.html` в браузере; для редактирования удобнее пользоваться `editor.html` на опубликованном сайте.
